# ConvolutionShader

## Import

ConvolutionShader is an addon, and must be imported explicitly, see [Installation#Addons](https://threejs.org/manual/#en/installation).

```js
import { ConvolutionShader } from 'three/addons/shaders/ConvolutionShader.js';
```

## Properties

### .[ConvolutionShader](#~ConvolutionShader) : [ShaderMaterial~Shader](ShaderMaterial.html#~Shader) (inner, constant)

Convolution shader ported from o3d sample to WebGL / GLSL.
