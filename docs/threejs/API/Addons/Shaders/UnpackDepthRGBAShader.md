# UnpackDepthRGBAShader

## Import

UnpackDepthRGBAShader is an addon, and must be imported explicitly, see [Installation#Addons](https://threejs.org/manual/#en/installation).

```js
import { UnpackDepthRGBAShader } from 'three/addons/shaders/UnpackDepthRGBAShader.js';
```

## Properties

### .[UnpackDepthRGBAShader](#~UnpackDepthRGBAShader) : [ShaderMaterial~Shader](ShaderMaterial.html#~Shader) (inner, constant)

Depth visualization shader that shows depth values as monochrome color.
