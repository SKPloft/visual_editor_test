# BitonicSort

### new [BitonicSort](#BitonicSort)( renderer : [Renderer](Renderer.html), dataBuffer : [StorageBufferNode](StorageBufferNode.html), options : Object )

Constructs a new light probe helper.

**renderer**

The current scene's renderer.

**dataBuffer**

The data buffer to sort.

**options**

Options that modify the bitonic sort.

Default is `{}`.
