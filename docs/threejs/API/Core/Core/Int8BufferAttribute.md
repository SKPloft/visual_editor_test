# Int8BufferAttribute

Convenient class that can be used when creating a `Int8` buffer attribute with a plain `Array` instance.

## Constructor

### new [Int8BufferAttribute](#Int8BufferAttribute)( array : Array.<number> | Int8Array, itemSize : number, normalized : boolean )

Constructs a new buffer attribute.

**array**

The array holding the attribute data.

**itemSize**

The item size.

**normalized**

Whether the data are normalized or not.

Default is `false`.
