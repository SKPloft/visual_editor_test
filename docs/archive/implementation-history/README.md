# Archived Implementation History

These files preserve the repository's former M0–M7 implementation tracker and working notes. They describe completed prototype work, stale follow-ups, and plans that were never necessarily approved under the current product process.

They are historical context only:

- `IMPLEMENTATION_TRACKER.md` — former milestone dashboard and future milestone outline.
- `MILESTONE_NOTES.md` — milestone observations and proposed M6/M7 behavior.
- `DECISIONS_LOG.md` — informal implementation-era decisions and follow-ups.
- `BUGS_DEBT.md` — former mixed active/resolved debt list.

Do not update these files or implement unfinished entries directly. Current product decisions come from Lark; approved engineering work is represented by an OpenSpec change. Active durable behavior belongs in `docs/`, code, and tests.
