# Archived Local Product Plans

These files preserve the repository's original product thinking, roadmap, and UX drafts. They are historical references, not the source of truth for current Nook product direction.

## Current product-planning authority

Current MVP scope, UX direction, collaboration context, and product priorities live in Lark:

- [项目：Nook](https://vrcd-community.feishu.cn/wiki/ILvDwglemixrBekqtDFc4b6Rnwb) — current project context and shared product understanding
- [MVP前工作图](https://vrcd-community.feishu.cn/wiki/HTrmwgVa5i31JSkP6bDcoJWinId) — working scratchpad for near-term MVP experiments

When these archived files conflict with Lark, follow Lark for product decisions.

## Archived files

- `DRAFT.md` — early MVP methodology notes and brainstorming
- `PRODUCT.md` — original product definition, persona, scope, and success metrics
- `ROADMAP.md` — original M0–M7 milestone sequence
- `USER_FLOWS.md` — original happy paths, editor state machine, and shortcut plan

## What remains authoritative in this repository

The repository remains the source of truth for implemented technical behavior and engineering contracts, including:

- `editor/` — active implementation
- `docs/IMPLEMENTATION_TRACKER.md` — implementation status as last reconciled with the code
- `docs/CANONICAL_FORMAT.md` — canonical scene-data contract
- `docs/UNITY_EXPORT.md` — Unity export behavior and constraints
- `docs/ADR/` — accepted architecture decisions
- `docs/NOTES/` — implementation observations, technical decisions, bugs, and debt

Do not silently update these archived files to reflect new plans. Add current product work to Lark and update active technical documents only when implementation or engineering contracts change.
