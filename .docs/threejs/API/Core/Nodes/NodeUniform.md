# NodeUniform

[NodeBuilder](NodeBuilder.html) is going to create instances of this class during the build process of nodes. They represent the final shader uniforms that are going to be generated by the builder. A dictionary of node uniforms is maintained in [NodeBuilder#uniforms](NodeBuilder.html#uniforms) for this purpose.

## Constructor

### new [NodeUniform](#NodeUniform)( name : string, type : string, node : [UniformNode](UniformNode.html) )

Constructs a new node uniform.

**name**

The name of the uniform.

**type**

The type of the uniform.

**node**

An reference to the node.
